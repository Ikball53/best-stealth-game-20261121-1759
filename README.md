# Moonlight Museum — 3 levels, 9 patrols, keyboard + mouse

A top-down stealth game set in a museum after closing time. Slip past guards on fixed patrols, hide behind display cases, pillars and planters, steal the Moon Gem, and reach the exit unseen.

How to play:
- WASD / arrow keys move; hold Shift to sneak (slower, but suspicion fills more slowly).
- Click anywhere to toss a coin — the nearest guard leaves patrol to investigate the noise.
- Vision cones turn orange then red as suspicion rises; break line of sight behind cover and suspicion drains, so a near miss is recoverable.
- Caught three times on one floor restarts that floor.
- Floors: Main Gallery (2 guards), Gem Vault (3 guards, gem required), Night Wing (4 guards, gem required).

Open `game/index.html` in any browser — no build step, no network needed.
